Technical treatment
All ten files are local, self-contained SVGs with explicit viewBox attributes.
No scripts, event handlers, foreignObject, embedded images/fonts, external
resources, or runtime dependencies are included. Artwork paths and source brand
colors/gradients are retained, except the explicitly removed background shapes
described below. XML serialization/whitespace and editor-only metadata were
normalized in the original seven assets; these changes do not redraw the marks.
The additional Power Pages, Power Platform, and Visual Studio Code assets are
byte-for-byte copies of the SVGs in their first-party icon archives; inspection
found no unsafe content requiring removal. Do not recolor these assets
with CSS filters to match the website's paper/forest-green or evening themes.
Normal SVG namespace identifiers are not downloaded resources.
